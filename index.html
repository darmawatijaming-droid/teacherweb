Guide: Menulis Markdown

Kolom KontenMarkdown di Google Spreadsheet mendukung format Markdown. Gunakan referensi berikut untuk menulis konten Anda.

Elemen Sintaks Markdown Hasil / Keterangan
Heading # Judul Utama
## Sub Judul
### Sub Sub		 Hingga level 6 dengan jumlah #
Bold **teks tebal** Teks muncul tebal
Italic *teks miring* Teks muncul miring
Link [teks tautan](https://url.com) Teks yang bisa diklik menuju URL
Image ![alt teks](https://url-gambar.com/img.jpg) Menampilkan gambar dari URL
List - Item satu
- Item dua		 Daftar bullet points
Blockquote > Kutipan penting Blok kutipan dengan garis samping

Tips Menulis di Spreadsheet

  • Pastikan header kolom pertama bernama Judul, Tanggal, Kategori, dan KontenMarkdown.
  • Sel yang berisi Markdown panjang sebaiknya di-wrap dengan tanda kutip ganda (") agar baris baru tidak membuat baris CSV baru.
  • Publikasikan Sheet via File → Share → Publish to web → CSV.
  • Setelah mengedit Sheet, tunggu beberapa menit agar cache Google ter-refresh.
